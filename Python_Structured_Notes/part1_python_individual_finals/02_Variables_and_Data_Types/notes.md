# Variables and Data Types

Variables store values. Common types are int (whole number), float (decimal), str (text), and bool (True or False).

Each example is saved separately as a `.py` file.

## Example 1: Integer — Easy

**Purpose:** Stores a whole number.

**Code:**

```python
age = 17
print(age)
print(type(age))
```

**Explanation:**
- `age = 17` — Stores a value or calculation in a variable.
- `print(age)` — Displays information in the terminal.
- `print(type(age))` — Displays information in the terminal.

**Sample output/result:**

```text
17; <class 'int'>
```
