# Python Final Project — Part 1

This folder contains 8 Python topics. Each topic folder contains:
- `notes.md`: topic introduction, 8 code examples, explanations, and sample results.
- `example_01.py` to `example_08.py`: individual runnable Python files.

## Topics
1. Print and Input
2. Variables and Data Types
3. Operators
4. Conditional Statements
5. Loops
6. String Operations
7. Functions
8. Basic File Handling

## Running an example in VS Code
1. Open this main folder in VS Code.
2. Open a topic folder and choose an example `.py` file.
3. Run it using the Run button, or type `python example_01.py` in the terminal.
4. For input examples, type your answer in the terminal.
5. For file-handling examples, run the create/write examples before the read examples when needed.

Run file-handling examples from their own topic folder so their text files are easy to locate. The sample login program is for learning conditions only, not secure authentication.
